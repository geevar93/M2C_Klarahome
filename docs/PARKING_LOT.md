**Every row carries a state and, if it is open, an owner.** Step 28B swept the ledger a second time
and gave one to each; the vocabulary is deliberately small:

| | Meaning |
|---|---|
| ✅ | Closed. The row names the step that closed it and what landed. |
| ℹ️ | An accepted decision, not a debt. Nothing is waiting on a step, and none should be invented. |
| ⏳ | Open, with **Owner: Step 29–33** — a step that has not run yet will do it. |
| 📋 | Open, with **Owner: Backlog (post-MVP)** — recorded, accepted, and outside the MVP. There is no remaining step that schedules it, and inventing one to hold it would be dishonest bookkeeping. |
| ⛔ | Open and blocked on something this repository does not control — a provisioned account, a remote, a live gateway. Each names the step that unblocks it. |
